# Chirru Portfolio v2

Production-oriented personal portfolio platform built with React and Java Spring Boot.

## Stack

- React + Vite + Tailwind CSS + Framer Motion
- React Router + TanStack Query + Fetch API
- Java 21 + Spring Boot + Spring Security + JWT
- Spring Data JPA + Hibernate + Flyway
- PostgreSQL
- Cloudinary
- Docker + GitHub Actions + Nginx

## Structure

```text
backend/    Spring Boot REST API
frontend/   Public portfolio
admin/      Admin dashboard
```
